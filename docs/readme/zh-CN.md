# PDF 图像编辑器 使用手册

在 PDF 里切分、移动、替换图片，**保留原有文字层**。

[English](en-US.md)

[返回项目首页](../../README.md) · [架构设计](../architecture.md) · [配置与数据格式](../configuration.md)

---

## 1. 它解决什么

扫描件和图文混排的 PDF 里，经常需要把一张大图切开、抠出中间一块、或者盖掉某个水印。用通用 PDF 编辑器做这些事，要么得把整页栅格化（文字层就没了），要么得在 Illustrator 里折腾。

这个工具把每一页拆成「背景 + 独立的图片对象」：

- **背景**保留原文档的文字、矢量与批注，按目标 DPI 现渲染；
- **图片对象**可以单独拖动、缩放、切分、删除、换图。

保存时只把图片换掉，其余内容原样不动。

## 2. 功能一览

**看**

- 页面按当前缩放自动选 DPI 渲染，放大不发虚
- 滚轮滚动、`Ctrl`+滚轮以指针为锚缩放、`Space`+拖动或中键拖动平移
- 浅色 / 深色两套主题，跟随系统或手动切换
- 页边距参考线，四边边距可调

**改**

- 拖动、四角等比缩放（按住 `Alt` 自由比例）、四边单向拉伸
- 多选（`Shift` 加选，限同一页）：小框之外套一个大框，拖大框等比缩放整组
- 从空白处拖出选框，框住哪几张就选哪几张
- 跨页拖动：拖到另一页就归到那一页
- 切分：在图上落几条切线，然后「仅保留此格 / 提取此格 / 按格切分」
- 置顶 / 置底、删除、方向键微调
- 从剪贴板粘贴图片（`Ctrl+V`）
- 用系统默认程序外部编辑某张图，改完回填

**存**

- 只替换图片，文字、矢量、批注、书签、链接全部保留
- 先写临时文件再替换，就地保存时首次留一份 `.bak.pdf`
- 导出指定页为新 PDF
- 黑白化预处理：另存一份去掉底灰的副本，原文件不动

## 3. 安装

需要：

- Windows 10 1803 以上（或 Windows 11）
- 系统里有 **WebView2 Runtime**（Win11 与绝大多数 Win10 已自带；没有的话从微软官网装一次）
- [uv](https://docs.astral.sh/uv/)

```bat
setup.bat
```

它会检查 `uv`，然后建 `.venv` 并装依赖。装完之后想升级依赖或换机器，重跑一次即可，版本由 `uv.lock` 锁定。

包索引固定在项目根的 `uv.toml`（官方 PyPI）。国内网络慢的话，把 `uv.toml` 里的 `url` 换成镜像再执行 `uv lock`；锁文件会跟着变成镜像地址，这类改动只在本机用，不要提交。

## 4. 启动

```bat
run.bat
```

用 `pythonw.exe` 启动，不会弹控制台。从任何目录调用都行——程序内部所有路径都按「程序目录」推导，与当前工作目录无关。

## 5. 界面

```
┌──────────────────────────────────────────────────────────────┐
│ 打开  保存  另存为 │ 文件名 ● │ ↶ ↷ │ − 100% + 适合宽度 100% │ … │
├───────────────────────────────────────────────┬──────────────┤
│                                               │   属性       │
│                 画布（页面纵向排列）           │  缩略图      │
│                                               │  页码/位置/尺寸│
│                                               │  操作按钮     │
├───────────────────────────────────────────────┴──────────────┤
│ 分割条（仅在分割模式出现）                                     │
└──────────────────────────────────────────────────────────────┘
```

**顶栏**

| 区域 | 内容 |
|---|---|
| 左侧 | 打开、保存、另存为；文件名与未保存圆点 |
| 中间 | 撤销 / 重做、缩放（`−` / 百分比输入 / `+` / 适合宽度 / 100%） |
| 右侧 | 预处理、导出页、重新加载、切换深浅色、设置、显示/隐藏属性栏 |

**画布**

页面纵向排列，滚动到哪一页就渲染哪一页。画布左下角有「当前页 / 总页数」的浮动提示，属性栏底部也显示同一行；顶栏右侧的忙碌条会显示打开、预处理这类长任务的进度。

**属性栏**

- 没选中：提示 + 「粘贴图片」按钮
- 选中一张：缩略图、页码、位置（pt）、尺寸（pt），以及「切分 / 置顶 / 置底 / 外部编辑 / 删除」
- 选中多张：提示 + 「删除」；画布上多出一个可整体缩放的大框

**分割条**

进入分割模式后出现在画布底部，实时显示已落的横线 / 竖线数量，以及三个动作按钮。按钮上的 `kbd` 会跟着自定义键位变。

## 6. 打开与查看

### 打开

点「打开」或按 `Ctrl+O`。文件对话框默认停在程序目录下的 `pdfs/`，这个目录不存在会自动创建——把常用 PDF 放进去能省几次跳转。

打开失败会提示原因（文件损坏、加密、页数异常），详细堆栈写在日志里。

### 缩放

| 操作 | 效果 |
|---|---|
| `Ctrl` + 滚轮 | 以指针位置为锚缩放 |
| `Ctrl+=` / `Ctrl+-` | 放大 / 缩小（每次 20%） |
| `Ctrl+0` | 适合宽度 |
| `Ctrl+1` | 回到 100% |
| 顶栏百分比框 | 输入数字后回车，直接跳到该比例 |

缩放范围 10% – 800%。缩放过程中只改页面的显示尺寸，位图按「档位」重新取：比例跨过一档才向后端要新图，中间的连续缩放不会反复传输。

### 平移

`Space` + 拖动，或按住鼠标中键拖动。松开 `Space` 回到选择模式。

### 页面跳转

属性栏底部有页码输入框，输入后回车或点「跳转」。只接受 1 到总页数之间的整数。

## 7. 编辑图片

### 选中

- 单击选中一张；`Shift` + 单击加选 / 减选
- **多选只能在同一页**：跨页加选会把选择换成新点的那一张，并提示一句
- 从空白处拖出一个选框，与框相交的图片全部选中——只要有一点压到就算
- 点空白处（不拖动）取消选择
- `Ctrl+A` 全选**当前页**的所有图片

### 移动

拖动选中框即可。拖动超过 3px 才算一次移动，所以单击不会误触。多选时拖任意一张，整组一起走。

### 缩放

选中一张图时，四周有八个手柄：四个角，加上四条边的中点。

| 手柄 | 行为 |
|---|---|
| 四个角 | 默认**等比**，按住 `Alt` 变自由比例 |
| 四条边 | 只拉伸一个方向，因此会改变长宽比 |

边手柄是为「PDF 里的显示比例和图片本身的像素比例不一致」准备的：一张方形图标被拉成扁的，靠拖上下边就能压回去，不必重新切图。像素数据不动，改的只是它在页面上的矩形。

设置里可以关掉「八个手柄」，只留四个角。

最小尺寸 4pt，再小就拒绝——否则矩形会翻面。

等比缩放是**按长边驱动**的：宽图只看横向位移，竖图只看纵向位移。这样拖动的手感和指针严格对应，不会出现「竖着拖 1px、宽度跳 10px」。

### 多选与组框

选中两张以上时，每张图保留自己的小框，外面多出一个大框：

- 小框上**没有手柄**，缩放交给大框；
- 大框也有八个手柄：拖角等比缩放整组，拖边只拉一个方向；
- 组里所有图按同一比例缩放，相对位置和间距一起变；
- 组里最小的那张不会小于 4pt，整组也不会被拖出页面；
- 拖动组里的任意一张，整组一起移动。

### 微调

| 键 | 位移 |
|---|---|
| 方向键 | 1pt |
| `Shift` + 方向键 | 10pt |
| `Ctrl` + 方向键 | 0.2pt |

方向键微调不参与自定义键位，避免和全局快捷键互相干扰。

### 跨页

把图拖到另一页上松开，它就归到那一页，页码同步更新。目标页如果还没被打开过，后端会先把那页原有的图片读进模型——否则保存时模型和文件对不上。

### 层级

`Ctrl+U` 置顶、`Ctrl+L` 置底，只影响同一页内部的叠放顺序。

### 删除

选中后按 `Delete`。被删的图会从画布上消失，但它在原 PDF 里占的位置会记进「墓碑表」，保存时照样擦掉——否则保存完它又回来了。

### 粘贴

`Ctrl+V` 把剪贴板里的图片贴到当前页，居中、宽度为页宽的 40%。浏览器复制的 PNG / JPEG 直接透传；截图工具放的 DIB 会手工解析。

### 外部编辑

选中一张图，`Ctrl+Shift+E`：程序把这张图写到临时目录，用系统默认程序打开。你在外部改完、保存、关掉外部程序后，回到本程序点确认，图片就回填了。

回填只换图片内容，显示位置和尺寸保持不变。

### 撤销 / 重做

`Ctrl+Z` / `Ctrl+Y`。撤销栈只存几何与图片 id，不复制像素，所以深度可以开得很大（默认 100，设置里可调 10–500）。

一次连续拖动算一条记录；切分、粘贴这类结构变化也是一条，撤销时整体回退。

## 8. 切分

选中**一张**图，按 `E` 或点属性栏的「切分」进入分割模式。

1. **落切线**：在图内点击落一条横线；按住 `Shift` 点击落竖线。线可以落任意多条，位置按点击处算。
2. **看格子**：光标所在的格子会高亮，分割条上的「仅保留此格 / 提取此格」随之可用。
3. **执行**：
   - `1` 仅保留此格——其余部分丢弃
   - `2` 提取此格——把这一格从原图里挖掉（原图留一个白洞），抠出来的部分独立成一张
   - `R` 按格切分——所有格子各成一张图
4. **反悔**：`Ctrl+Z` 撤回**最后一刀**（按落笔顺序，不区分横竖），不是整次进入分割。
5. **退出**：`Esc` 或分割条上的「取消」。执行任一动作后会自动退出。

分割模式下全局快捷键暂停，两套键位可以绑同一个键而互不冲突。

> 「提取」和「仅保留」的区别：提取是**挖洞**，原图还在，只是少了一块；仅保留是**替换**，原图整个消失，只剩那一格。

## 9. 保存与导出

### 就地保存

`Ctrl+S`。第一次就地保存时会在旁边留一份 `<文件名>.bak.pdf`，之后再保存不会重复备份。

保存期间窗口底部会弹出「正在保存，暂时不要修改文档」，画布和快捷键同时锁住；写完自动收起。大文件保存要几秒，这段时间的点击不会被当成编辑。

### 另存为

`Ctrl+Shift+S`，默认文件名是 `<原名>-edited.pdf`。保存后以新文件为基线，继续编辑仍然作用在新文件上。

### 保存做了什么

1. 按每张图的**原始位置**（`src_rect`）做 redaction，把原图从页面内容里摘掉；
2. 按每张图**当前的位置**（`rect`）重新插入，按 z 序叠放；
3. 写临时文件 → 重新打开校验页数 → 替换目标文件。

因此文字、矢量、批注、书签、链接全部保留，没有「要不要丢文字」这种选项。

两个细节：

- **批注**：`apply_redactions` 会连带删掉落在矩形里的批注，所以保存时先把页面的 `/Annots` 摘下来，做完再挂回去，批注对象一个字节都不动。
- **旋转图片**：`insert_image` 只能按 90° 步进放置，非轴对齐的图片不参与编辑，原样留在背景里。

保存完成会提示写到了哪个路径、替换了多少张图。个别图片出问题不会中断保存，而是列一份清单：

| 提示 | 含义 |
|---|---|
| 第 N 页有图片被裁到页内 | 图片超出了页面边界，保存时被夹取 |
| 第 N 页有图片被跳过 | 尺寸为零，没有插入 |
| 第 N 页有图片插入失败 | 编码或写入出错，原图仍在背景里 |
| 第 N 页擦除失败 | redaction 没做成，原图可能残留 |
| 第 N 页批注未能还原 | 极端情况下 `/Annots` 写回失败 |

### 导出页

`Ctrl+E`，输入页码（例如 `1-3,5,7-9`，中文逗号也认），导出成一个新 PDF。

- 导出的是**当前文件**的内容，所以有未保存修改时会拦下来，先保存再导出；
- 页码越界、区间反向、格式不对都会被跳过，并在结果里列出来，不会静默少页。

### 重新加载

顶栏的 ↻ 按钮从磁盘重新读当前文件，丢弃内存里的编辑。有未保存修改时会先确认。

## 10. 黑白化预处理

扫描件常带着一层灰底，存档和打印都不好看。顶栏的「预处理」把文档里每张图转成灰度，再把亮于阈值的像素压成纯白，然后**另存为新文件**。

点按钮先弹一个说明框，确认之后才让你选源文件和目标文件。这一步不碰当前打开的文档，也不需要先打开 PDF。

| 项 | 说明 |
|---|---|
| 处理对象 | 页内的位图；文字、矢量、批注原样保留 |
| 跳过的图 | 带透明通道的（logo、水印）——压成二值会把透明区域变成黑块 |
| 阈值 | 默认 235，可在 `config/app.json` 的 `preprocess_threshold` 里改（0–255） |
| 输出 | 你选的目标文件；与源文件相同时会被拒绝 |
| 进度 | 顶栏右侧的忙碌条显示「已处理 / 总数」 |

处理完会提示存到了哪里、一共处理了多少张图。想重来就再跑一次——源文件从头到尾没被改动过。

> 阈值越高，越多浅灰被压成白，235 适合多数扫描件。调到 200 以下会把浅色线条和淡彩一起抹掉。

## 11. 快捷键

**全部可在「设置 → 快捷键」里改**，改完立刻生效；同一作用域里出现重复组合键会当场拦下。

| 键 | 作用 |
|---|---|
| `Ctrl+O` | 打开 |
| `Ctrl+S` / `Ctrl+Shift+S` | 保存 / 另存为 |
| `Ctrl+E` | 导出页 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+A` | 全选当前页 |
| `Ctrl+V` | 粘贴图片 |
| `Ctrl+0` / `Ctrl+=` / `Ctrl+-` / `Ctrl+1` | 适合宽度 / 放大 / 缩小 / 100% |
| `Delete` | 删除选中 |
| `Ctrl+U` / `Ctrl+L` | 置顶 / 置底 |
| `Ctrl+Shift+E` | 外部编辑当前图片 |
| `Ctrl+I` | 显示 / 隐藏属性栏 |
| `Ctrl+,` | 设置 |
| `E` | 进入分割模式 |
| 方向键（`Shift` 加速、`Ctrl` 细调） | 微调位置 |
| `Space` + 拖动 / 中键拖动 | 平移画布 |

| 键 | 作用 |
|---|---|
| `1` / `2` | 仅保留光标所在格 / 提取光标所在格 |

## 12. 设置

`Ctrl+,` 或点顶栏齿轮。

**设置面板没有「保存」和「取消」**：每一处改动都当场写进 `config/app.json`，关掉弹窗不会撤销任何东西。面板左下角有红色的「重置所有」，把设置、快捷键、参考线一起恢复默认。

| 项目 | 范围 | 说明 |
|---|---|---|
| 界面语言 | 中文 / English | 立即生效，标题与提示一起换 |
| 主题 | 浅色 / 深色 | 也可点顶栏的月亮/太阳按钮 |
| 撤销上限 | 10–500 | 改小只影响之后入栈的记录 |
| 参考线 | 开 / 关 | 画布上的页边距线 |
| 八个手柄 | 开 / 关 | 关掉后图片只剩四个角手柄 |
| 页边距 | 0–300 mm | 左 / 上 / 右 / 下四边 |
| 快捷键 | 两套作用域 | 点输入框后按下想要的组合键；「重置快捷键」只恢复键位 |

快捷键用 `event.code` 归一化，所以 `Ctrl+Shift+S` 与 `Ctrl+S` 不会因为 Shift 改变字符而混淆，不同键盘布局下也一致。

## 13. 文件与目录

```
程序目录/
├─ config/app.json     设置（语言、主题、参考线边距、键位）
├─ logs/               每次启动一个日志文件
├─ temp/               外部编辑的临时文件，启动时清理一天前的残留
└─ pdfs/               打开对话框的默认目录
```

- `config/`、`logs/`、`temp/`、`pdfs/` 都不进版本库，删掉会自动重建。
- 配置文件是原子写入（临时文件 + 替换），中途崩溃不会留下半个文件。手改坏了不会静默重置，而是报错并指出文件名。
- 配置里未知的键会原样保留，方便跨版本共存。

## 14. 常见问题

**打开 PDF 报错**
文件可能损坏、没有有效页面，或者根本不是 PDF。日志里有完整堆栈；先确认能用别的阅读器打开。

**保存失败，提示文件被占用**
目标 PDF 正在被别的程序打开（Acrobat、Edge 的标签页都会占用）。关掉它再保存。另外只读文件会提前拦下并提示。

**某张图选不中 / 拖不动**
两种情况：图片所在页被整体旋转过，或者图片在页面里是斜着放的。`insert_image` 只能按 90° 步进插入，硬编辑只会得到错位放大的一张，所以这类图留在背景里，保存时原样保留。属性栏会提示该页有几张这样的图。

**保存后原图还在**
说明那张图没有被识别成可编辑对象（同上），或者擦除时失败了。看保存结束的提示清单，第 N 页会写明原因。

**切分后大图又回来了**
不会。每页的图片只在第一次打开时读进模型，之后不再重复读，所以删掉、切掉的图不会复活。

**预处理没处理某张图**
那张图带透明通道（logo、水印），二值化会把它的透明区域压成黑块，所以跳过。这类图要保留原样。

**快捷键按了没反应**
先看是不是在分割模式（全局快捷键暂停），再看是不是输入框有焦点（有焦点时按键交给输入框）。改过键位的话，设置里会标出冲突。

**界面一片空白**
WebView2 运行时缺失或版本过旧。装一次 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 再启动。

## 15. 已知限制

- **旋转页不可编辑**：整页旋转过的文档，该页所有图片都不参与编辑。
- **非轴对齐图片不可编辑**：斜放、翻转的图片留在背景里。
- **旋转角度只能是 90° 的倍数**：插入接口的限制，不是配置项。
- **切分只作用于一张图**：多选状态下进入分割会提示先选一张。
- **导出前必须先保存**：导出读的是磁盘上的文件，不是内存里的编辑。
- **预处理只处理页内位图**：矢量线条和文字不参与二值化，灰底若是矢量填充会留在原处。
