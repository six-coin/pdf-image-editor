# PDF 图像编辑器 使用手册

在 PDF 里切分、移动、替换图片，保留原有文字层。

---

## 1. 它解决什么

扫描件和图文混排的 PDF 里，经常需要把一张大图切开、抠出中间一块、或者盖掉某个水印。用通用 PDF 编辑器做这些事，要么得把整页栅格化（文字层就没了），要么得在 Illustrator 里折腾。

这个工具把每一页拆成「背景 + 独立的图片对象」：

- **背景**保留原文档的文字、矢量与批注，按目标 DPI 现渲染；
- **图片对象**可以单独拖动、缩放、切分、裁白边、删除、换图。

保存时只把图片换掉，其余内容原样不动。

## 2. 功能一览

**看**

- 页面按当前缩放自动选 DPI 渲染，放大不发虚
- 滚轮滚动、`Ctrl`+滚轮以指针为锚缩放、`Space`+拖动或中键拖动平移
- 浅色 / 深色两套主题，首次启动按系统偏好定一次，之后手动切换
- 页边距参考线，四边各可以有多条；另有可配置的对齐线，移动和缩放元素时自动吸附

**改**

- 拖动、四角等比缩放（按住 `Alt` 自由比例）、四边单向拉伸
- 多选（`Shift` 加选，限同一页）：小框之外套一个大框，拖大框等比缩放整组
- 多选后合并成一张：分辨率取选中图里最高的那张，按上下层关系合成，透明区域落到白底，结果不透明
- 从空白处拖出选框，框住哪几张就选哪几张
- 跨页拖动：拖到另一页就归到那一页
- 切分：在图上落几条切线，然后「仅保留此格 / 提取此格 / 按格切分」
- 置顶 / 置底、删除、方向键微调
- 从剪贴板粘贴图片（`Ctrl+V`）
- 用系统默认程序外部编辑某张图，改完回填
- **文本框**：字体、字号、行高、颜色可调，一个框里能混排多种字体
- **荧光笔**：横向色带，正片叠底，压住文字也不挡字

**存**

- 只替换图片，文字、矢量、批注、书签、链接全部保留
- 先写临时文件再替换，就地保存时把原文件复制一份到数据目录的 `backup\`
- 导出指定页为新 PDF
- 黑白化预处理：另存一份去掉底灰的副本，原文件不动

## 3. 安装

需要：

- Windows 10 1803 以上（或 Windows 11）
- 系统里有 **WebView2 Runtime**（Win11 与绝大多数 Win10 已自带；没有的话从微软官网装一次）
- [uv](https://docs.astral.sh/uv/)

```bat
setup.bat
```

它会检查 `uv`，然后建 `.venv` 并装依赖。装完之后想升级依赖或换机器，重跑一次即可，版本由 `uv.lock` 锁定。

包索引固定在项目根的 `uv.toml`，默认用阿里云镜像（`https://mirrors.aliyun.com/pypi/simple`），`uv.lock` 里的下载地址也一并指向镜像，两者都随仓库提交。要换回官方源，把 `url` 改成 `https://pypi.org/simple` 再执行 `uv lock`。

## 4. 启动

```bat
main.bat
```

用 `pythonw.exe` 启动，不会弹控制台。从任何目录调用都行——程序启动时会把工作目录固定到程序目录，内部路径也一律按「程序目录」与系统目录推导。

**第一次运行**时先选界面语言（默认跟随 Windows 的系统语言，没有对应语言包就用英语；点一下另一个选项，界面立刻切成那种语言），再读一遍使用说明。这两步必须按按钮走完，Esc 和点空白都关不掉。这是唯一的入口，不存在「启动错程序」的情况。

## 5. 界面

窗口分五块：顶栏、左侧工具条、画布、右侧属性栏，以及画布底部的分割条（只在分割模式出现）。下面按区域说明。

**顶栏**

| 区域 | 内容 |
|---|---|
| 左侧 | 打开、保存、另存为；文件名与未保存圆点 |
| 中间 | 撤销 / 重做、缩放（`−` / 百分比输入 / `+` / 适合宽度 / 100%） |
| 右侧 | 预处理、导出页、重新加载、切换深浅色、设置、显示/隐藏属性栏 |

**左侧工具条**

常驻、不能关，三个图标决定「在页面上按下去会发生什么」：

| 图标 | 模式 | 在页面上按下时 |
|---|---|---|
| 箭头 | 选择 | 选中、拖动、缩放手柄、框选（默认） |
| T | 文本 | 落一个文本框并进入编辑 |
| 马克笔 | 荧光笔 | 横向拖出一条荧光带 |

**画布**

页面纵向排列，只渲染「当前页 + 后一页 + 前一页 + 后两页」这四页。跳到别处时，之前渲染过的页留在原地不卸载，但也不会为远处的页预先渲染。画布左下角有「当前页 / 总页数」的浮动提示，属性栏底部也显示同一行；顶栏右侧的忙碌条会显示打开、预处理这类长任务的进度。

**属性栏**

- 没选中：提示 + 「粘贴图片」按钮
- 选中一张图片：缩略图、页码、位置（pt）、尺寸（pt），以及「切分 / 置顶 / 置底 / 外部编辑 / 删除」
- 选中文本框或荧光带：页码、位置、尺寸，以及「删除」
- 选中多个：提示 + 「删除」；画布上多出一个可整体缩放的大框

**分割条**

进入分割模式后出现在画布底部，实时显示已落的横线 / 竖线数量，以及四个动作按钮（仅保留 / 提取 / 涂白 / 按格切分）。按钮上的 `kbd` 会跟着自定义键位变。

## 6. 打开与查看

### 打开

点「打开」或按 `Ctrl+O`。文件对话框默认停在数据目录下的 `pdfs/`，这个目录不存在会自动创建——把常用 PDF 放进去能省几次跳转。设置里可以改「打开文件时的默认目录」；留空就回到 `pdfs/`。

也可以**直接把 PDF 拖进窗口**：还没有打开文件时拖进来就打开它；已经打开了一个文件时，如果有未保存的修改，会先问你保存、不保存还是取消。拖进来的是别的类型会提示只能打开 PDF，一次拖多个只认第一个。

打开失败会提示原因（文件损坏、加密、页数异常），详细堆栈写在日志里。

### 缩放

| 操作 | 效果 |
|---|---|
| `Ctrl` + 滚轮 | 以指针位置为锚缩放 |
| `Ctrl+=` / `Ctrl+-` | 放大 / 缩小（每次 20%） |
| `Ctrl+0` | 适合宽度 |
| `Ctrl+1` | 回到 100% |
| 顶栏百分比框 | 输入数字后回车，直接跳到该比例 |

缩放范围 10% – 800%。缩放过程中只改页面的显示尺寸，位图按「档位」重新取：比例跨过一档才向后端要新图，中间的连续缩放不会反复传输。

### 平移

`Space` + 拖动，或按住鼠标中键拖动。松开 `Space` 回到选择模式。

### 页面跳转

属性栏底部有页码输入框，输入后回车或点「跳转」。只接受 1 到总页数之间的整数。

跳转是瞬移，不会一路滚过去：50 页的文档从第 1 页跳到第 30 页，只会加载第 30、31、29、32 页，中间的 28 页一张都不渲染。

## 7. 编辑图片

### 选中

- 单击选中一张；`Shift` + 单击加选 / 减选
- **多选只能在同一页**：跨页加选会把选择换成新点的那一张，并提示一句
- 从空白处拖出一个选框，与框相交的图片全部选中——只要有一点压到就算
- 点空白处（不拖动）取消选择
- `Ctrl+A` 全选**当前页**的所有图片（仅选择工具）；`Esc` 取消选择（仅选择工具）

### 移动

拖动选中框即可。拖动超过 3px 才算一次移动，所以单击不会误触。多选时拖任意一张，整组一起走。

只选中**一张图片**时，可以把它拖到页面外（拼版、做溢出时有用），松手不会弹回页内；多选整组和文本框仍然夹在页内。页外部分在打印/导出时会被页边裁掉，但位置会保留在文件里。

### 缩放

选中一张图时，四周有八个手柄：四个角，加上四条边的中点。

| 手柄 | 行为 |
|---|---|
| 四个角 | 默认**等比**，按住 `Alt` 变自由比例 |
| 四条边 | 只拉伸一个方向，因此会改变长宽比 |

边手柄是为「PDF 里的显示比例和图片本身的像素比例不一致」准备的：一张方形图标被拉成扁的，靠拖上下边就能压回去，不必重新切图。像素数据不动，改的只是它在页面上的矩形。

缩放时，被拖的那条边（角手柄是两条边）**不会越过页面边缘**：指针拖出页面就停在页边，不会把图压扁或裁掉。只选中**一张图片**时例外，可以把边拖到页面外。

拖动边或角时，正在移动的边会吸附参考线和对齐线，吸住时画一条绿色提示线。角手柄等比缩放时只吸更近的那一条边，另一条按原比例跟随，不会为了贴线把长宽比拉坏。

设置里可以关掉「八个手柄」，只留四个角。

最小尺寸 4pt，再小就拒绝——否则矩形会翻面。

等比缩放是**按长边驱动**的：宽图只看横向位移，竖图只看纵向位移。这样拖动的手感和指针严格对应，不会出现「竖着拖 1px、宽度跳 10px」。

### 多选与组框

选中两张以上时，每张图保留自己的小框，外面多出一个大框：

- 小框上**没有手柄**，缩放交给大框；
- 大框也有八个手柄：拖角等比缩放整组，拖边只拉一个方向；
- 组里所有图按同一比例缩放，相对位置和间距一起变；
- 组里最小的那张不会小于 4pt，整组也不会被拖出页面；
- 拖动组里的任意一张，整组一起移动；
- **文本框和荧光带也能进组**：它们跟着挪位置，但宽高不变——拉大整组不会把字也拉大。

### 裁掉白边

选中一张或多张图片，按 `G`（或属性栏「裁掉白边」）。程序从四边往里收，直到每一刀切掉的部分都够白；保留的是所有非白像素的包围盒，所以切掉的面积最大。图片在页面上的内容位置不变，只是矩形和像素一起变小。整次操作可以用 `Ctrl+Z` 一次撤销。

- 按 BT.601 算灰度，**灰度 ≥ #F8F8F8（248）就算白**；不再要求三个通道都必须是 255。透明和半透明像素先压在白底上再算；
- 254 的扫描底灰会被裁掉，247 的浅灰仍算内容；
- 整张都够白或本来就没有浅色边时不动，状态栏提示「没有可裁掉的白边」；
- 多选时选中的必须都是图片；混选文本框或荧光带会直接拒绝。

### 合并图片

选中同一页的两张以上图片，属性栏会出现「合并图片」。合并后，这些图变成**一张**，原来的小框、组框一起消失，选择落到结果上。

合并只把选中的图片对象压成一张位图；页面上的文字、矢量和选区外的图片不受影响。选区内的空隙会变成白底，可能盖住其下的内容。

| 规则 | 说明 |
|---|---|
| 范围 | 结果覆盖所有选中图的并集矩形；图与图之间的空隙填成纯白 |
| 分辨率 | 取选中图里**最高**的那张：像素密度 = 图片像素宽 ÷ 页面上的宽（pt）。密度最高的图，每个像素在页面上占的面积最小 |
| 缩放 | 其余图用**双三次插值**放大到同一密度；正常情况只会放大，不会缩小 |
| 上下层 | 从下往上按 z 序合成，上层盖住下层，和画布上看到的一致 |
| 结果层级 | 取选中图里最靠上的那一层（最大的 z）。合并把多层压成一层，原本夹在中间、没被选中的图无法再保持原来的相对位置 |
| 透明 | 先在底下铺一层**纯白实心**底，再按 alpha 往上叠加；半透明图正常混合，空隙和透明像素露出纯白。结果**没有 alpha 通道**，压在任何底色上都一致 |
| 撤销 | 整次合并是一条记录，`Ctrl+Z` 一次全部还原 |

结果是一张**不透明的矩形位图**：并集里的空隙和透明像素都是纯白，会盖住其下的页面内容。

限制：一次合并的结果最大 4000 万像素、边长 12000px。超过时整体等比缩小，状态栏会说明缩小后的尺寸。

**只合并图片**：选择里只要有文本框或荧光带，属性栏就不显示这个按钮；后端也会拒绝，覆盖层没有「分辨率」可言，不该被压进位图。

### 微调

| 键 | 位移 |
|---|---|
| 方向键 | 1pt |
| `Shift` + 方向键 | 10pt |
| `Ctrl` + 方向键 | 0.2pt |

方向键微调不参与自定义键位，避免和全局快捷键互相干扰。

### 跨页

把图拖到另一页上松开，它就归到那一页，页码同步更新。目标页如果还没被打开过，后端会先把那页原有的图片读进模型——否则保存时模型和文件对不上。

### 层级

`Ctrl+U` 置顶、`Ctrl+L` 置底，只影响同一页内部的叠放顺序。

### 删除

选中后按 `Delete`。被删的图会从画布上消失，但它在原 PDF 里占的位置会记进「墓碑表」，保存时照样擦掉——否则保存完它又回来了。

### 粘贴

`Ctrl+V` 把剪贴板里的图片贴到当前页，居中、宽度为页宽的 40%。浏览器复制的 PNG / JPEG 直接透传；截图工具放的 DIB 会手工解析。

### 外部编辑

选中一张图，`Ctrl+Shift+E`：程序把这张图写到临时目录，用系统默认程序打开。你在外部改完、保存、关掉外部程序后，回到本程序点确认，图片就回填了。

回填只换图片内容，显示位置和尺寸保持不变。

### 表格框线处理

选中一张表图，右侧属性栏点「表格框线处理」。程序会自动识别图片里的表格框线，把它们拉成**严格水平/竖直**的直线，并把线宽固定成 3px。

- **最短 170px**：短于 170 像素的横线/竖线一律不当表格线，手写批注里的小笔画不会被拉直。
- **不许孤立线**：一条线的任一端必须落在另一条垂直线上（corner 或丁字口）；只是从别的线中间穿过去不算接上，两端都悬空的线直接丢弃。
- **长线直接收**：贯穿图宽/高 75% 以上的边框先认下来；其余线只有**两端都搭在已认线上**才收，所以长单元格分隔线也能处理，而手写的长横线（两端不搭线）不会被误当成表格线。
- **线宽固定 3px**：不再测量原线宽度；原来 2px 的外框、4px 的内线，统一画成 3px。
- **线芯纯黑**：线芯用 `(0,0,0)`，按像素栅格对齐，画出来是干净的黑色，不再保留扫描的深灰。
- **端点按 corner / T 型收放**：T 型口只把竖线收到横线的中心线（线头多出 9px 以内都算同一个口），不会在横线外侧多出一截；corner 才延到对面线的外像素边，把外角填满。
- **只动线，不动字**：擦除只擦每条线自己的窄带，文字区域不受影响。

处理结果是一张新图片，可以用 `Ctrl+Z` 撤销。识别不到表格线时会提示「没有识别到表格线，图片未改动」，不会改图。

**不适用**：整页倾斜超过约 0.5°、拍照透视畸变、虚线/断线（默认不连接）；只有平行横线的三线表没有 corner / 丁字口，也会按孤立线跳过。如果表格线是 PDF 矢量对象而不是图片，这个功能也不适用——它处理的是选中的那张图片的像素。

### 撤销 / 重做

`Ctrl+Z` / `Ctrl+Y`。撤销栈只存几何与图片 id，不复制像素，所以深度可以开得很大（默认 100，设置里可调 10–500）。

一次连续拖动算一条记录；切分、粘贴这类结构变化也是一条，撤销时整体回退。

## 8. 切分

选中**一张**图，按 `E` 或点属性栏的「切分」进入分割模式。选中多张时进不去——切线只能属于一张图，界面会提示一次只能切一张。

1. **落切线**：在图内点击落一条横线；按住 `Shift` 点击落竖线。`Shift` 一按下（或一松开）虚线预览立刻跟着转向，不用再动一下鼠标。线可以落任意多条，位置按点击处算。
2. **看格子**：光标所在的格子会高亮，分割条上的「仅保留此格 / 提取此格 / 涂白此格」随之可用。
3. **执行**：
   - `1` 仅保留此格——其余部分丢弃
   - `2` 提取此格——把这一格从原图里挖掉（原图留一个白洞），抠出来的部分独立成一张
   - `3` 涂白此格——只把这一格涂白，不产出那一小块
   - `R` 按格切分——所有格子各成一张图
4. **反悔**：`Ctrl+Z` 撤回**最后一刀**（按落笔顺序，不区分横竖），不是整次进入分割。
5. **退出**：`Esc` 或分割条上的「取消」。执行任一动作后会自动退出。

分割模式下全局快捷键暂停，两套键位可以绑同一个键而互不冲突。

> 「提取」「涂白」「仅保留」的区别：提取是**挖洞**，原图还在、少了一块，抠出来的那一块独立成对象；涂白也是挖洞，但抠出来的部分直接扔掉；仅保留是**替换**，原图整个消失，只剩那一格。

## 9. 文本框

左栏切到「文本」模式（T 图标），在页面上单击就落一个文本框，**落点就是它的左上角**。

设置里可以填「新建文本框的默认文本」：之后每次新建都会自动填入这段文字；**按住 `Ctrl` 单击空白**则新建一个空文本框，方便临时写别的内容。

### 编辑

- **单击**选中，可以拖动；**双击**进入编辑，光标就在框里，同时自动切到「文本」工具（左栏的文本按钮会亮起）。
- 编辑时 `Enter` 换行，`Esc` 或点框外结束并保存。
- **点框外**：结束编辑并取消选中这个文本框，不会顺手在空白处新建一个。
- 编辑时框的高度会跟着内容实时长高或缩短；行尾多按一次回车也算一行，和保存后的高度一致。
- 换行规则与保存后一致：中文逐字断，收尾标点（`，。、；：！？` 等）不会单独跑到下一行行首，开头标点（`（《「【` 等）不会孤零零留在行尾；英文按词断，超长词硬断。
- 内容清空后离开，这个框会被删掉——不会留下一个看不见的空对象。
- 字号只取整数（px），工具栏上的 `−` / `+` 一档一档调，也可以直接输入。
- **行高**是字号的倍数，默认 1.15，范围 0.8–3。

### 工具栏

工具栏钉在文本框左上角，选中就出现：

| 控件 | 说明 |
|---|---|
| 字体 | 微软雅黑 / 宋体 / 仿宋 / 楷体 / 黑体 / Times New Roman |
| 字号 | 6–200 px，默认 14（与 Edge 的批注同号） |
| 行高 | 0.8–3 倍，默认 1.15 |
| 颜色 | 蓝（默认）/ 红 / 绿 / 黑，前三种取自 Edge 的批注配色 |

**允许混排**：选中一部分文字再点字体，只有那一段换字体。同一个框里可以一段宋体、一段仿宋。工具栏的字体名会跟着光标所在的文字段走，不会一直停在第一段的字体上。

### 宽度

文本框只有**左右两个手柄**，拖动改宽度——文字不缩放，只是重新换行；高度永远按行数算，拖不出来。默认宽度 4.5cm，可以在设置里改。

内容多到超过页面时，框会继续向下延伸，不会被裁掉；拖动时只把左上角夹在页内，底部允许溢出。

### 「当前默认值」

新建的文本框用哪套样式，看「上一个编辑过的文本框」：

- 还没编辑过任何文本框时，用设置里的默认值（微软雅黑 / 14px / 蓝 / 行高 1.15 / 宽 4.5cm）；
- 一旦编辑过某个框，下一个新建的框就沿用它的样式——和 Edge 的行为一致。

这条规则不显示在界面上：它是「最近用过的那一套」，不是又一个设置项。打开新文档时清空。

### 落盘

文本框保存成**真正的文字**，不是图片，也不是 PDF 批注：

- 在 Edge、Chrome、Acrobat 里都能正常显示、选中、搜索、复制，打印也带着；
- 字体**子集化**后嵌进 PDF，只带用到的那些字——六个字体全量嵌入是 41 MB，子集化之后一页文字几十 KB；
- 原文档的字体一个字节都不动。

程序在自己的内容流首行留了一个标记，所以重新打开时还认得出「这是本程序建的框」，可以继续编辑。别的 PDF 里的文字没有这个标记，和以前一样是烘焙在背景里的，不能操作。

编辑器里的**背景图**不会把这些文字画进去——它们由界面单独绘制，移动时不会在原位留下残影；打印、导出和在别的阅读器里打开时，文字仍然在页面上。

## 10. 荧光笔

左栏切到「荧光笔」模式（马克笔图标），光标变成一个虚线竖长方体，按住左键**横向拖动**就是一条带子。

- 只支持横向，不支持自由画线；
- 松手才真正建出来，拖动过程中只有一个预览块；拖得太短（不足 4pt）当作没画；
- 固定黄色 `#FFF066`，和 Edge 的荧光笔一致；高度默认 15px，可以在设置里改（整数 px）；
- 只有黄色一种，没有调色面板。

### 它是「颜色叠加」，不是盖一块色块

荧光带用的是**正片叠底**（PDF 里的 `/BM /Multiply`）：

| 底色 | 结果 |
|---|---|
| 白纸 | 亮黄 |
| 灰色底纹 | 暗黄 |
| 纯黑 | 还是黑，看不出变化 |

这正是荧光笔该有的行为——文字和线条不会被盖住，只是被「染」了一层色。

荧光带**只能选中和挪位置**：没有手柄，不能改大小。它和文本框一样，可以和图片一起选中、一起移动；整组缩放时只跟着挪位置，尺寸不变。

## 11. 保存与导出

### 就地保存

`Ctrl+S`。就地保存会先把原文件复制到**数据目录**的 `backup\` 里，文件名是 `YYYYMMDD-原标题.bak.pdf`。**每个文档每天只备份第一次**：同一天再保存时，同名备份已经在了，就直接跳过，不会再生成 `(1)`、`(2)`。备份不放在源文件旁边，是为了让要交付、归档的 PDF 目录里不混进 `.bak.pdf`。

备份超过保留天数（默认 30 天，设置里可改）会在下次启动时删掉。备份目录里的 PDF 不允许直接打开——它是保存前的快照，对着它改等于改了副本。

保存期间窗口底部（和其他提示同一条状态栏）会挂出「正在保存，暂时不要修改文档」，画布和快捷键同时锁住；写完自动收起。大文件保存要几秒，这段时间的点击不会被当成编辑。

### 另存为

`Ctrl+Shift+S`，默认文件名是 `<原名>-edited.pdf`。保存后以新文件为基线，继续编辑仍然作用在新文件上。

### 保存做了什么

1. 撤掉上一版由本程序画上去的文本框与荧光带；
2. 按每张图的**原始位置**（`src_rect`）做 redaction，把原图从页面内容里摘掉；
3. 按每张图**当前的位置**（`rect`）重新插入，按 z 序叠放；
4. 把这一页的文本框与荧光带重新画上去（字体在这一步子集化）；
5. 写临时文件 → 重新打开校验页数 → 替换目标文件。

因此文字、矢量、批注、书签、链接全部保留，没有「要不要丢文字」这种选项。

两个细节：

- **批注**：`apply_redactions` 会连带删掉落在矩形里的批注，所以保存时先把页面的 `/Annots` 摘下来，做完再挂回去，批注对象一个字节都不动。
- **旋转图片**：`insert_image` 只能按 90° 步进放置，非轴对齐的图片不参与编辑，原样留在背景里。

保存完成会提示写到了哪个路径、替换了多少张图。个别图片出问题不会中断保存，而是列一份清单：

| 提示 | 含义 |
|---|---|
| 第 N 页有图片被裁到页内 | 图片超出了页面边界，保存时被夹取 |
| 第 N 页有图片被跳过 | 尺寸为零，没有插入 |
| 第 N 页有图片插入失败 | 编码或写入出错，原图仍在背景里 |
| 第 N 页擦除失败 | redaction 没做成，原图可能残留 |
| 第 N 页批注未能还原 | 极端情况下 `/Annots` 写回失败 |
| 第 N 页文本框或荧光笔没能写入 | 覆盖层绘制出错；图片部分已经处理完，这一页的文字没有落盘 |
| 文件已保存，但界面没能重新打开它 | 磁盘上的文件是好的，点顶栏的重新加载即可继续 |

### 导出页

`Ctrl+E`，输入页码（例如 `1-3,5,7-9`，中文逗号也认），导出成一个新 PDF。

- 导出的是**当前文件**的内容，所以有未保存修改时会拦下来，先保存再导出；
- 页码越界、区间反向、格式不对都会被跳过，并在结果里列出来，不会静默少页。

### 重新加载

顶栏的 ↻ 按钮从磁盘重新读当前文件，丢弃内存里的编辑。有未保存修改时会先确认。

## 12. 黑白化预处理

扫描件常带着一层灰底，存档和打印都不好看。顶栏的「预处理」把文档里每张图转成灰度，再把亮于阈值的像素压成纯白，然后**另存为新文件**。

点按钮先弹一个说明框，里面有两条路：

- **处理当前打开的文档**：直接用正在编辑的那个文件，省掉再选一次源文件。要求当前文档没有未保存的修改——处理的是磁盘上的版本，跑完再打开结果会把改动盖掉；
- **处理其他文档**：另选一个 PDF，不要求先打开它。

选完源文件再选目标文件，两者相同会被拒绝。

| 项 | 说明 |
|---|---|
| 处理对象 | 页内的位图；文字、矢量、批注原样保留 |
| 跳过的图 | 带透明通道的（logo、水印）——压成二值会把透明区域变成黑块 |
| 阈值 | 默认 235，可在设置面板或数据目录的 `app.json` 里改 `preprocess_threshold`（0–255） |
| 输出 | 你选的目标文件；与源文件相同时会被拒绝 |
| 进度 | 顶栏右侧的忙碌条显示「已处理 / 总数」 |

处理完会提示存到了哪里、一共处理了多少张图，然后问要不要立刻打开处理后的文件。想重来就再跑一次——源文件从头到尾没被改动过。

> 阈值越高，越多浅灰被压成白，235 适合多数扫描件。调到 200 以下会把浅色线条和淡彩一起抹掉。

## 14. 设置

`Ctrl+,` 或点顶栏齿轮。

**设置面板没有「保存」和「取消」**：每一处改动都当场写进数据目录里的 `app.json`，关掉弹窗不会撤销任何东西。面板左下角有红色的「重置所有」，把设置、快捷键、参考线、对齐线一起恢复默认。

设置按类别分成几大块——常规、文本框、荧光笔、日志、备份、快捷键、关于——块与块之间用一条细灰线隔开。

| 项目 | 范围 | 说明 |
|---|---|---|
| 界面语言 | 中文 / English | 立即生效，标题与提示一起换；列表按语言代码排序 |
| 主题 | 浅色 / 深色 | 没有「跟随系统」；首次启动按系统偏好定一次。也可点顶栏的月亮/太阳按钮 |
| 打开文件默认目录 | 任意文件夹 | 打开 PDF 时从这里开始；留空使用数据目录下的 `pdfs/` |
| 撤销上限 | 10–500 | 改小只影响之后入栈的记录 |
| 参考线 | 开 / 关 | 画布上的页边距线 |
| 八个手柄 | 开 / 关 | 关掉后图片只剩四个角手柄 |
| 页边距 | 0–300 mm | 左 / 上 / 右 / 下四边，每边可以有多条：输入框里用英文逗号分隔，例如 `10, 50`。存下来是升序去重的列表，回填时统一格式化成 `10, 50` |
| 对齐线 | 0–300 mm | 同样是四边多值，默认是五条参考线再加左边 85mm；移动和缩放元素时用来吸附，平时不显示 |
| 默认字体 | 六种字体 | 新建文本框的字体 |
| 默认字号 | 6–200 px | 默认 14；只能取整数 |
| 默认颜色 | 蓝 / 红 / 绿 / 黑 | 新建文本框的颜色，默认蓝 |
| 默认宽度 | 10–300 mm | 默认 45（4.5cm） |
| 默认行高 | 0.8–3 倍 | 默认 1.15；是字号的倍数 |
| 新建文本框默认文本 | 任意文本 | 新建时自动填入；按住 `Ctrl` 新建则不填 |
| 荧光笔默认高度 | 4–200 px | 默认 15 |
| 日志级别 | 调试 / 常规 / 警告 / 错误 | 改完立刻生效，日志仍写在同一个文件里 |
| 自动清空日志 | 开 / 关 | 启动时删掉超过保留期的日志文件；关掉就一直留着 |
| 日志保留天数 | 1–365 | 默认 30；关掉上面的开关时这一项不起作用 |
| 备份保留天数 | 1–3650 | 默认 30；启动时删掉 `backup\` 里超过这个天数的备份 |
| 快捷键 | 两套作用域 | 点输入框后按下想要的组合键；「重置快捷键」只恢复键位 |

**对齐线**和参考线分开配置：参考线是常驻的版心提示，对齐线在**移动和缩放**时起作用。拖图片、文本框、荧光带时，元素的左边、竖直中线、右边会吸竖直对齐线，上边、水平中线、下边会吸水平对齐线；缩放时只有手柄带着走的那两条边参与吸附（边手柄是一条），参考线也会参与。吸住的一瞬间画一条 2px 的绿色提示线，比参考线粗一倍、层级也更高，松手就消失。吸附半径是 6 个屏幕像素，缩放后手感一致；如果吸附会把元素推出页面，这一轴就不吸——缩放时如果单张图片允许出页，则不受此限。

快捷键用 `event.code` 归一化，所以 `Ctrl+Shift+S` 与 `Ctrl+S` 不会因为 Shift 改变字符而混淆，不同键盘布局下也一致。

设置面板最后是「关于」：

| 项目 | 说明 |
|---|---|
| 版本 | 当前程序版本，来自 `pyproject.toml` |
| 数据目录 | 配置与默认 PDF 目录的位置，默认 `%PROGRAMDATA%\six-coin\pdf-image-editor`。左边是输入框，右边「更改」「重置」：选一个目录后会自动补上 `pdf-image-editor` 这一层，**重启后**把旧目录的内容复制过去、再删掉旧目录。改完点输入框下面的「立即重启」；有未保存的修改时先拦下，让你保存 |
| 使用说明 | 打开当前语言的使用手册（找不到就用英文） |

## 15. 文件与目录

程序目录只放代码；运行期文件全在系统目录里。

```
程序目录\
├─ main.bat / main.pyw   入口
├─ setup.bat             装环境
└─ app\                  全部代码

%PROGRAMDATA%\six-coin\pdf-image-editor\     数据目录（可更改）
├─ app.json             设置（语言、主题、参考线边距、文本框与荧光笔默认值、键位）
├─ backup\              就地保存前的备份，每个文档每天一份，YYYYMMDD-原标题.bak.pdf
└─ pdfs\                打开对话框的默认目录

%LOCALAPPDATA%\six-coin\pdf-image-editor\
├─ logs\                每次启动一个日志文件
├─ locks\               锁
└─ data-dir.txt         数据目录指针

%TEMP%\six-coin\pdf-image-editor\            外部编辑的临时文件，启动时清理一天前的残留
```

- 日志写在 `%LOCALAPPDATA%\six-coin\pdf-image-editor\logs\`，文件名以 `main_` 开头，每次启动一个，单个文件超过 5 MB 轮转。默认只留最近 30 天，更早的在启动时删掉。
- 备份写在数据目录的 `backup\` 里，每个文档每天只留第一份，默认保留 30 天。换数据目录时它跟着一起搬过去。
- 数据目录里的 `app.json` 是原子写入（临时文件 + 替换），中途崩溃不会留下半个文件。手改坏了不会静默重置，而是报错并指出文件名。
- 配置里未知的键会原样保留，方便跨版本共存。
- 数据目录的最后一层恒是项目代号：选 `D://Data` 得到 `D://Data//pdf-image-editor`。换目录时旧内容在重启后复制过去：目录按同名合并，目标已有的同名文件不覆盖；复制不成功就什么都不动，并在设置里说明原因，不会出现「目录换了、设置没了」。切换成功之后旧目录会被删掉。

## 16. 常见问题

**打开 PDF 报错**
文件可能损坏、没有有效页面，或者根本不是 PDF。日志里有完整堆栈；先确认能用别的阅读器打开。

**保存失败，提示文件被占用**
目标 PDF 正在被别的程序打开（Acrobat、Edge 的标签页都会占用）。关掉它再保存。另外只读文件会提前拦下并提示。

**某张图选不中 / 拖不动**
两种情况：图片所在页被整体旋转过，或者图片在页面里是斜着放的。`insert_image` 只能按 90° 步进插入，硬编辑只会得到错位放大的一张，所以这类图留在背景里，保存时原样保留。属性栏会提示该页有几张这样的图。

**保存后原图还在**
说明那张图没有被识别成可编辑对象（同上），或者擦除时失败了。看保存结束的提示清单，第 N 页会写明原因。

**切分后大图又回来了**
不会。每页的图片只在第一次打开时读进模型，之后不再重复读，所以删掉、切掉的图不会复活。

**预处理没处理某张图**
那张图带透明通道（logo、水印），二值化会把它的透明区域压成黑块，所以跳过。这类图要保留原样。

**保存后找不到 `.bak.pdf`**
备份不再放在源文件旁边，而在数据目录的 `backup\` 里（设置 → 关于 → 数据目录）。文件名带日期前缀，例如 `20261123-report.bak.pdf`。每个文档每天只备份第一次，同一天再保存不会再多出文件——所以看到的是「当天打开时的样子」，不是最后一次保存前的样子。

**文本框里的汉字和屏幕上的字形不一样**
那段文字用了 Times New Roman 这类没有汉字的字体，落盘时会退回一个兜底字体——能显示，但字形不是屏幕上那个。想完全一致，就把那一段换成中文字体。

**快捷键按了没反应**
先看是不是在分割模式（全局快捷键暂停），再看是不是正在保存（保存期间画布和快捷键都会锁住），最后看是不是输入框有焦点（有焦点时按键交给输入框）。改过键位的话，设置里会标出冲突。

**界面一片空白**
WebView2 运行时缺失或版本过旧。装一次 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 再启动。

**改了数据目录，重启后没变化**
先看设置面板里那行小字：还写着「重启后生效」就是还没复制成功（目标盘不存在、文件被占用、没有写权限）。把目录改回当前那个或点「重置」就能取消这次改动；修好之后点「立即重启」——手动关掉窗口再打开也行，但必须是真退出：旧进程还在时，再双击一次只会把已经开着的那个窗口提到前面，不会开第二个。

## 17. 已知限制

- **旋转页不可编辑**：整页旋转过的文档，该页所有图片都不参与编辑。
- **非轴对齐图片不可编辑**：斜放、翻转的图片留在背景里。
- **旋转角度只能是 90° 的倍数**：插入接口的限制，不是配置项。
- **切分只作用于一张图**：多选状态下进入分割会提示一次只能切一张。
- **导出前必须先保存**：导出读的是磁盘上的文件，不是内存里的编辑。
- **预处理只处理页内位图**：矢量线条和文字不参与二值化，灰底若是矢量填充会留在原处。
- **一次只预加载四页**：远处的页要等滚到附近才渲染，快速拖动滚动条时会先看到灰块。
- **旋转页不能加文本框和荧光笔**：整页旋转过的页坐标系和画布对不上，和「旋转页的图片不可编辑」同一个理由。
- **拖宽度时文字不实时重排**：文本框宽度拖到松手才重新换行，拖动过程中会看到文字被裁一下。
- **Times New Roman 下的中文走系统回退字体**：字体本身没有中文字形，这类混排的断行可能和保存后有一两个字的差异；五种中文字体（雅黑 / 宋体 / 仿宋 / 楷体 / 黑体）与保存结果逐行一致。
- **文本框和荧光带只在能读标记的阅读器里可编辑**：它们是页面内容流，别的阅读器里是普通内容，能看、能选、能打印，但不能像批注那样再改。
- **同一页的文本框与荧光带总是画在图片之上**：它们不参与图片的 z 序（置顶 / 置底只作用于图片）。
- **合并会把多层压成一层**：结果取选中图里最上层；夹在选中图之间、没被选中的图无法再保持原来的相对位置。
