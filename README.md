# PDF Image Editor

**PDF 图像编辑器** —— 在 PDF 里切分、移动、替换图片，保留原有文字层。

Windows 单机工具，双击即用，不需要联网。

运行环境：Windows 10 1803 以上（或 Windows 11）+ [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Win11 与多数 Win10 已自带）+ [uv](https://docs.astral.sh/uv/)。

```bat
setup.bat   :: 建环境
run.bat     :: 启动
```
